## Aim

Design a cam using geometric and analytical methods, and design a gear profile from the given user specifications.

## Summary

Used *GeoGebra* to geometrically design a cam for a desired follower profile, and verified the design analytically by plotting the governing functions in *MATLAB*.

Designed a gear by plotting the involute function in *MATLAB*.

## Takeaways

This was my first MATLAB project, and it laid the foundation for the many modelling and simulation projects that followed.
